> *"Ban đầu chỉ có 500 đồng và một cái xe bán đồ ăn vỉa hè. Một lúc sau bạn đang điều hành cả đế chế ẩm thực liên hành tinh!"*

**Snack Empire** là một tựa game mô phỏng kinh doanh (Business Tycoon / Restaurant Management / Idle Incremental) chạy **hoàn toàn trên trình duyệt web**, mang đậm phong cách hài hước meme Gen Z, hiện đại và lôi cuốn.

---

## 🌟 Tính Năng Nổi Bật

- 🛒 **Vòng lặp kinh doanh chân thực**: Mua nguyên liệu ➔ Chế biến ➔ Phục vụ khách đói bụng ➔ Nhận tiền ting ting ➔ Tái đầu tư ➔ Mở rộng.
- 👨‍🍳 **Tự động hóa toàn diện**: Tuyển dụng Bếp trưởng Bob và Thu ngân Gen Z Linh để quán tự động phục vụ 24/7 ngay cả khi bạn treo máy đi ngủ!
- 📦 **Quản lý kho & Nhà cung cấp**: Hợp tác với Chợ Đầu Mối Siêu Rẻ, Nông Trại Hữu Cơ Eco Farm, Ninja Express hoặc Nhà cung cấp chuẩn Michelin VIP. Tính năng **Auto-Restock** tự động đặt hàng khi cạn kho.
- 🍔 **Hệ thống Menu phong phú**: Burger Bò Phô Mai, Khoai Tây Chiên Lắc, Soda Bạc Hà, Gà Rán Sốt Hàn, Cà Phê Muối Bạc Xỉu, Trà Sữa Trân Châu, Waffle Matcha Uji, cho đến Burger Bò Wagyu Dát Vàng 24K!
- 🏪 **10 Bậc Cửa Hàng (Tier 1 - Tier 10)**: 
  1. Xe Bán Dạo "Khởi Nghiệp"
  2. Kiosk Nhỏ Góc Phố
  3. Cửa Hàng Máy Lạnh Chill
  4. Nhà Hàng Phố Đi Bộ
  5. Chuỗi 10 Chi Nhánh Đô Thị
  6. Tập Đoàn Nhượng Quyền Quốc Gia
  7. Đại Tập Đoàn Niêm Yết IPO
  8. Tổ Hợp Food Mall Quốc Tế
  9. Kỳ Lân FoodTech Robot AI
  10. **Đế Chế Ẩm Thực Sao Hỏa 🚀**
- 📱 **SnackTok & Viral Marketing**: Mạng xã hội giả lập SnackTok, đăng bài câu like, bắt trend ẩm thực, chạy chiến dịch marketing bùng nổ, theo dõi thị phần đối thủ cạnh tranh.
- 🎲 **Sự kiện ngẫu nhiên (Random Events)**: Cơn sốt Matcha Uji 🔥, Trời mưa rào vắng khách 🌧️, Hot TikToker review triệu view 🌟, Nhà đầu tư thiên thần rót vốn 💼, Chập cầu chì bếp nấu 🚨.
- 🏆 **Nhiệm vụ & Thành tựu Meme Gen Z**: Hệ thống Quest nhận thưởng nóng và Thành tựu hài hước (*"Bro Cần Đi Chạm Cỏ 🌱💀"*, *"Nằm Ngửa Ăn Tiền 🛋️"*, *"Vua Đầu Bếp Burger 👑"*).
- 🚀 **Prestige / Tái Sinh Vĩnh Viễn**: Đạt mốc doanh thu lớn, reset lại quán để nhận **Empire Points**. Mua các nâng cấp vĩnh viễn giúp vòng chơi sau phát triển nhanh gấp 10 lần!
- 💤 **Offline / Idle Income**: Khi tắt máy hoặc đóng trình duyệt, hệ thống vẫn tự động tích lũy tiền và đơn hàng dựa trên đội ngũ nhân sự.
- 🔊 **Web Audio Synthesizer**: Toàn bộ hiệu ứng âm thanh (tiếng đếm tiền cha-ching, click, chuông nâng cấp, level up) được tổng hợp bằng Web Audio API thuần túy, không cần tải bất kỳ file mp3 bên ngoài nào, mượt mà 100%.
- 💾 **Hệ thống Lưu Dữ Liệu**: Tự động lưu `localStorage`, hỗ trợ Xuất (Export) & Nhập (Import) file JSON sao lưu với cơ chế kiểm tra tính hợp lệ bảo mật.

## 🚀 Cài Đặt & Chạy Thử Tại Local

### Yêu Cầu
- Node.js >= 18.x
- npm >= 9.x

### Các bước cài đặt:

```bash
# 1. Clone repository
git clone https://github.com/your-username/snack-empire.git
cd snack-empire

# 2. Cài đặt dependencies
npm install

# 3. Chạy môi trường phát triển (Dev server)
npm run dev
```

Mở trình duyệt tại: `http://localhost:5173`

### Chạy Unit Tests:
```bash
npm run test
```

### Build Production:
```bash
npm run build
```

### Xem thử bản Production Preview:
```bash
npm run preview
```

## 🌐 Hướng Dẫn Deploy

### 1. Deploy lên GitHub Pages (Tự Động)
Dự án đã có sẵn cấu hình tại `.github/workflows/deploy.yml` và `vite.config.ts` (`base: './'`).
1. Tạo repo mới trên GitHub và push mã nguồn lên nhánh `main`.
2. Vào **Settings** > **Pages** trên repository.
3. Trong mục **Build and deployment** > **Source**, chọn **GitHub Actions**.
4. Website sẽ tự động deploy và cung cấp URL truy cập trực tiếp!

### 2. Deploy lên Vercel / Netlify
- Chỉ cần kết nối repo với Vercel hoặc Netlify, framework preset chọn **Vite**, build command: `npm run build`, output directory: `dist`.
